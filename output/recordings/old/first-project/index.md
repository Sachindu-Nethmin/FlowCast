## Step 1: Create the Project

1. Open WSO2 Integrator.
2. Select **Create**.
3. Set **Integration Name** to `MyNewProject`.
4. Set **Project Name** to `FirstProject`.
5. Select **Browse**.
6. Select the project location and select **Open**.
7. Select **Create Integration**.
